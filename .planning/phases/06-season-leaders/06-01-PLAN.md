**init block** (CRITICAL — follow these patterns exactly to avoid double-fetch):
1. Call `fetchInitData()`
2. Launch collector on `viewState.map { Pair(it.selectedLeague, it.selectedStatOption) }.distinctUntilChanged().collect { (league, category) -> if (league != null) fetchLeaders(leagueId = league.id, statOption = category) }`

IMPORTANT: Do NOT use `.filterNotNull()` on the Pair — `selectedStatOption` is never null (enum with default). Guard with `if (league != null)` inside collect instead.

**Public methods:**
1. `fun onSeasonSelected(newSeason: Season)` — if different from current, update state with `selectedSeason = newSeason, selectedLeague = null`, then call `fetchLeaguesData(seasonId = newSeason.id)`. Copy verbatim from `StandingsViewModel.onSeasonSelected`.
2. `fun onLeagueSelected(newLeague: League)` — update state with `selectedLeague = newLeague`. Leaders fetch triggered reactively.
3. `fun onStatOptionChanged(newOption: LeagueStatLeaderOption)` — update state with `selectedStatOption = newOption`. Leaders fetch triggered reactively.
4. `fun onRefresh()` — same pattern as `StandingsViewModel.onRefresh`: if no season, fetchInitData; if no league, fetchLeaguesData; else fetchLeaders with current league and stat option.

**Private methods:**
1. `fetchInitData()` — copy from `StandingsViewModel.fetchInitData` exactly. Uses `getLeaguesInfo()`. On success: set seasons (sorted descending by num), leagues, selectedSeason (first), selectedLeague (first), fullScreenLoading=false. The reactive collector handles the initial leader fetch.
2. `fetchLeaguesData(seasonId: Int)` — copy from `StandingsViewModel.fetchLeaguesData`. Uses `getLeaguesForSeason(input)`. On success: set leagues, selectedLeague (first), fullScreenLoading=false. The reactive collector handles the leader fetch.
3. `fetchLeaders(leagueId: Int, statOption: LeagueStatLeaderOption)` — NEW. Uses `getLeagueLeaders(input = GetLeagueLeadersUseCase.Input(leagueId, statOption))`. On success: update `leaders = result, fullScreenLoading = false`. On error: `Logger.e("Error when fetching leaders data", error)` + update `error = error, fullScreenLoading = false`. Set `fullScreenLoading = true, error = null` before fetch.

**Error handling pattern:** Use `.onSuspendSuccess { }` and `.onSuspendGeneralError { }` exactly as in `StandingsViewModel`.
